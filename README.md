## ✨ Key Features

- **Embedded Clang/LLVM Toolchain**: Compiles and executes modern C++ (C++17/20) directly on Android without requiring an internet connection or external servers.
- **Tree-sitter Syntax Highlighting**: High-speed, incremental abstract syntax tree (AST) parser running in native C++ via JNI with Catppuccin Mocha theme.
- **Split Ergonomic Keyboard**: Zero-latency touch response, flick gesture support for numbers and symbols, and physical haptic feedback.
- **Analog Joystick Controller**: 360-degree cursor navigation with an adaptive acceleration curve.
- **GNOME Adwaita UI**: Responsive 3-column split container with full Zen Mode support, custom gutter line numbering, and interactive console sheet with STDIN dock.
